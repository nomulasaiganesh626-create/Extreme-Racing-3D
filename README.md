# Extreme Racing 3D

An original Godot 4 Android racing-game prototype, targeting landscape mobile play and devices such as the Vivo Y17s.

## Project

Open `ExtremeRacing3D/project.godot` with Godot 4. The source archive includes the main scene and GDScript files for the prototype garage/car builder.

## Current prototype scope

- Procedural original vehicle prototypes
- Garage and customization prototype code
- Landscape project configuration
- Experimental local-network multiplayer path

## Important status

This is a development prototype, not a finished commercial racing game. The project has not been runtime-tested in Godot or compiled into an Android APK in this delivery. Vehicle visuals are procedural prototypes; detailed production car models, complete racing content, and verified multiplayer remain future work.

## Android build

Use Godot 4 with the matching export templates, Android SDK, and Java SDK. Configure an Android export preset, then export an APK. See the [Godot Android export documentation](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html).

## Target device

Vivo Y17s. Keep rendering settings conservative on mobile; test on the actual device before release.
